# 📨 فرم مشارکت غیرفنی

## 📝 روش‌های پیشنهاد واژه

### روش ۱: ویرایش مستقیم فایل
اگر با Git آشنایی دارید، می‌توانید مستقیماً فایل `data/terms/` را ویرایش کنید:

1. [Fork کردن مخزن](https://github.com/bmhmdyan279-png/eng-terms-fa/fork)
2. ویرایش فایل `data/terms/`
3. ایجاد Pull Request

[راهنمای مشارکت](contribute.md)

### روش ۲: قالب‌های Issue
برای پیشنهاد ساختاریافته از قالب‌های آماده استفاده کنید:

- [پیشنهاد واژهٔ جدید](https://github.com/bmhmdyan279-png/eng-terms-fa/issues/new/choose)
- [اصلاح ترجمه](https://github.com/bmhmdyan279-png/eng-terms-fa/issues/new/choose)

!!! note "چرا ایمیل عمومی نداریم؟"
    برای جلوگیری از هرزنامه و متمرکزکردن بازبینی‌ها، پیشنهادها فقط از طریق
    Issue/PR پذیرفته می‌شوند — هر پیشنهاد یک شمارهٔ قابل پیگیری می‌گیرد.
